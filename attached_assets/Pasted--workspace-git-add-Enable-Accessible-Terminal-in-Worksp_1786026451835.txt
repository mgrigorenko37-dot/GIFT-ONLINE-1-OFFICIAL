Что такое Telegram-подарки (как актив для торговли)
С 2024–2025 года в Telegram появились коллекционные подарки — это уникальные NFT-подобные предметы на блокчейне TON. Их покупают за Telegram Stars (внутренняя валюта), они хранятся в профиле пользователя и их можно передавать. Уникальные («прокачанные») подарки имеют ограниченный выпуск, и на них уже есть вторичный рынок.

2. Интерфейс — Telegram Mini App

Пользователю не нужно выходить из Telegram

Матчинг-движок → находит совпадения, исполняет сделку

Главные технические вопросы
Эскроу подарков — как безопасно «заморозить» подарок на время сделки? Telegram API позволяет переводить подарки боту, бот держит их как эскроу-агент.

Ценообразование — в Stars или TON? Stars проще (внутри Telegram), TON даёт больше ликвидности.

KYC/антифрод — Telegram даёт верификацию через login widget, это достаточно для старта.

Комиссия — берёте % с каждой сделки (как биржа).
